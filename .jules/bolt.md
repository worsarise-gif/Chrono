## 2026-09-08 - Unnecessary React re-renders due to inline functions
**Learning:** React re-renders components when props change. Inline functions, like `() => handleImageClick(msg.imageUrl!)` in the `ChatArea.tsx` map over `messages` or inline arrow functions for `onImageClick` in `ResponseFormatter.tsx`, create a new function reference on every render, leading to unnecessary re-renders of the child components or triggering deeper React diffing than needed. Similarly, using non-memoized values in dependency arrays can cause unnecessary re-renders.
**Action:** Always wrap functions passed as props to child components (especially memoized components like `ResponseFormatter` or `ImageRenderer`) in `useCallback`. When dependencies update frequently (like a `messages` or `allImages` array), use the 'latest ref' pattern to stabilize the callback reference while still accessing the freshest state.
